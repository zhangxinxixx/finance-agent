## 合并前审阅修补：研究质量门

新详细研究请求由质量合同触发17项审阅，不再依赖`macro_causal`非空。缺宏观证据仍可声明缺失；不能因此跳过时间、前序、事实和权限检查。

新增`quality_gate_version=research_quality_gate.v1`，明确区分以下结果：

| 情况 | generation_status | review_status | quality_eligible | 研究结果status |
| --- | --- | --- | --- | --- |
| 生成完成且本轮审阅通过 | success | pass | true | success |
| 一次修订后仍有未通过项 | success | needs_revision | false | quality_blocked |
| Reviewer不可用（含修订后不可用） | success | unavailable | false | quality_blocked |
| 方法文件不可用或指纹不匹配，尚未调用模型 | unavailable | not_run | false | rule_fallback |
| 生成/正文解析失败 | failed | not_run | false | rule_fallback |

所有未通过项均阻断研究质量资格，包含P0错误；不是仅降低置信度。最多一次质量修订，只有修订后的完整审阅通过才解除阻断。`quality_eligible=true`仅表示本轮自动审阅合格，不表示同证据质量评分、盲评、正式Accepted、发布或交易许可。

被阻断的草稿、原始回复、审阅链和调用身份保留在审计对象，但不追加到协调器的判断摘要。正式报告/注册共用门禁拒绝这类对象；中文预览仅保留可核验数据及未通过说明。来源血缘完整与研究合格分开记录，影子评估不把这类草稿计作成功样本。协调器外层状态仍表示原有确定性计算结果，不能代替上述研究质量字段。

文件缺失、不可读、空文件、编码异常与指纹漂移返回明确原因、输入快照/校验指纹和恢复条件；不得用新方法偷偷重放旧请求。生成后才发现漂移时保留生成事实，审阅与质量资格阻断。恢复对应冻结材料，或明确创建绑定新版本的新请求。原规范与方法正文没有扩写，历史产物不回写；已终结的同一研究对象不自动重试。旧产物没有新质量字段，不能由缺省值追认合格；带质量合同但缺结论的对象再次申请正式交付时拒绝。

修补前6个真实协调器入口反例全部失败；修补后受影响回归253通过、1跳过，包含19个新门禁集成用例。唯一跳过项仍需`GOLD_DETAILED_ACCEPTANCE_SNAPSHOT`。全部模型回复为明确合成的测试替身，没有运行新的市场研究。旧版消息构造不追补质量合同；新详细研究在协调器入口强制要求合同。生成调用的审计输入保留独立副本，后来的审阅结果不能改写原调用输入。检查范围包含周报/旧版消息、worker、报告API、生成/审阅、文件与版本错误、三种中文展示、正式Markdown/结构化入口和影子样本选择；这仍不是实际研究质量验收。
